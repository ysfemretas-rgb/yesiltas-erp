# Yeşiltaş ERP

Yeşiltaş Teknoloji için geliştirilmiş ERP sistemi.

## Teknolojiler

- Next.js 14
- TypeScript
- Tailwind CSS
- shadcn/ui
- Supabase

## Kurulum

1. `npm install`
2. `.env.local` dosyasını oluşturun:
   ```
   NEXT_PUBLIC_SUPABASE_URL=your_url
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your_key
   ```
3. `npm run dev`

## Deploy

Vercel üzerinden otomatik deploy edilir.
