# Yeşiltaş ERP - PWA (Telefon Uygulaması) Kurulumu

## ⚠️ ÖNEMLİ: next-pwa KURMAYIN!

Önceki versiyonda `next-pwa` paketi kullanılıyordu ama Vercel'de build hatası verdi.
Bu versiyonda SADECE `manifest.json` kullanıyoruz. Daha basit, daha güvenli.

## 1. Dosyaları Kopyalayın

Bu ZIP'teki dosyaları projenize şu şekilde kopyalayın:

```
public/manifest.json          → public/manifest.json
public/icons/                 → public/icons/ (icon dosyalarını buraya)
```

## 2. Layout Düzenlemesi

app/layout.tsx dosyanızın başına şunları ekleyin:

```tsx
import type { Metadata, Viewport } from 'next'

export const metadata: Metadata = {
  title: 'Yeşiltaş Teknoloji ERP',
  description: 'Yeşiltaş Teknoloji ERP Yönetim Sistemi',
  manifest: '/manifest.json',
  appleWebApp: {
    capable: true,
    statusBarStyle: 'black-translucent',
    title: 'Yeşiltaş ERP',
  },
  icons: {
    icon: '/icons/icon-192x192.png',
    apple: '/icons/icon-192x192.png',
  },
}

export const viewport: Viewport = {
  width: 'device-width',
  initialScale: 1,
  maximumScale: 1,
  userScalable: false,
  themeColor: '#0f172a',
  viewportFit: 'cover',
}
```

## 3. Build ve Deploy

```bash
npm run build
```

Sonra GitHub Desktop'tan commit + push yapın. Vercel otomatik deploy edecek.

## 4. Telefona Kurulum

### Android (Chrome):
1. Sitenizi telefondan açın
2. Chrome menüsü (⋮) → "Ana ekrana ekle" veya "Uygulama yükle"
3. "Ekle" butonuna basın

### iPhone (Safari):
1. Sitenizi telefondan açın
2. Paylaş butonu (⎋) → "Ana Ekrana Ekle"
3. "Ekle" butonuna basın

### Artık telefonunuzda Yeşiltaş ERP uygulaması gibi çalışacak!

## NOT: next.config.js DEĞİŞTİRMEYİN!
